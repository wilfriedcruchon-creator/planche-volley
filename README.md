# Planche tactique volley

Planche tactique de volley qui fonctionne dans le navigateur, y compris hors ligne une fois installée.
Placez les joueurs et le ballon, tracez les déplacements, enchaînez des étapes animées et enregistrez vos tactiques.

Sur iPad : ouvrir le site dans Safari, puis Partager > Sur l'écran d'accueil.
