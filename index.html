Déplacez les joueurs comme d'habitude ; glissez sur le terrain vide pour tourner la vue. Choisissez la posture d'un joueur en le sélectionnant.

Étapes

Chaque étape garde les positions et les tracés. Lancez l'animation pour voir les joueurs se déplacer d'une étape à l'autre.

Équipes

La rotation fait avancer chaque joueur d'un poste : 2 → 1 → 6 → 5 → 4 → 3 → 2.

Sélection

Cliquez sur un joueur, le ballon, un plot ou un tracé pour le sélectionner et le déplacer.

Glissez un point pour déformer la zone, touchez le « + » au milieu d'un côté pour ajouter un point, double-touchez un point pour le supprimer.
